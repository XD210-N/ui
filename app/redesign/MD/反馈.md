## 设计缺失的内容

### ❌ 发送按钮没有逻辑

`RedesignHome.tsx` 中的橙色提交按钮没有 `onClick` 处理器。点击时不会调用任何运行时、触发任何 LLM 请求或执行任何操作。

### ❌ 没有对话运行时（Thread / MyRuntimeProvider）

旧的 UI 把所有内容包裹在 `<MyRuntimeProvider>` 中，所有 LLM 通信通过 `useExternalStoreRuntime` + LangGraph 流式传输来驱动。重新设计没有引入这些——没有消息列表、没有流式响应、也没有 AI 响应渲染。

### ❌ 没有预览窗口（ArtifactCanvas）

旧的 UI 在第三列渲染 `<ArtifactCanvas>`，显示由 `canvasStore` 驱动的实时工件/预览。重新设计没有画布、没有预览面板，也没有触发预览的方式。

### ❌ 文件上传不可用

创作器中的文件输入仅将 `fileCount` 计数器递增。所选文件从未传递给任何附件适配器或运行时。

### ❌ 没有对话线程列表/历史记录

旧的 UI 通过 `ThreadListPrimitive` 在侧边栏显示所有线程。重新设计没有历史面板——过去的对话无法访问。


参考建议：

1. 使用 `<MyRuntimeProvider>`（按 `activeProject.project_id` key）包裹 `RedesignHome`（或其页面），正如 `page.tsx` 当前所做的那样。
2. 将创作器的发送按钮连接到 `useComposer().send()` 或 `runtime.thread.append()`。
3. 将所选文件通过 `useComposer().attachFiles()` 传递给附件适配器。
4. 在第一次发送消息后，在面板/覆盖层中渲染 `<Thread>`（消息列表）。
5. 在预览面板/覆盖层中渲染 `<ArtifactCanvas>`。
6. 在现有的项目或设置面板中，或作为新的侧边栏，添加线程列表。
