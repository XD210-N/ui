# 原工程代码修改说明

当前阶段只在 `app/redesign` 内新增新 UI 路由、视觉层和连接层文件。

以下记录 `app/redesign` 文件夹外的甲方原始工程文件改动。每个原文件只保留一处记录，按改动点罗列。

后续如果必须改动原工程文件，请在对应文件章节内追加改动点，格式如下：

```tsx
xxxxxx（原代码）
```

```tsx
xxxxxx（新代码）
```

## lib/strings.ts

多语言核心定义。

**1. `Locale` 类型从 2 种扩展为 5 种**

```ts
export type Locale = "en" | "zh";
```

改为：

```ts
export type Locale = "zh-TW" | "zh" | "en" | "ja" | "ko";
```

**2. 首页品牌文案（zh）**

```ts
welcomeTitle: "你好！",
welcomeSubtitle: "今天想让我帮您构建什么？",
```

改为：

```ts
welcomeTitle: "Omnistack 让创意直达产品",
welcomeSubtitle: "从需求到量产，以自然语言驱动人机交互产品的全链路创新",
```

**3. `UIStrings` 新增文案字段**

新增 `uploadAttachmentLabel`、`settingsLabel`、`languageSettings`、`toolManual`、`closeManual`、`manual*` 系列（说明书弹窗）等字段。

**4. 新增三套语言对象，扩展 `localeStrings` 注册表**

```ts
export const localeStrings: Record<Locale, UIStrings> = { en, zh };
```

改为：

```ts
export const localeStrings: Record<Locale, UIStrings> = {
  "zh-TW": zhTW,
  zh,
  en,
  ja,
  ko,
};
```

- `zhTW` 继承 `...zh`，并覆盖为繁体文案，字段全覆盖。
- `ja` / `ko` 继承 `...en`，覆盖为日 / 韩文案。注意：未覆盖的字段会回退到英文，新增字段时需同步补译这两套。

## lib/strings-context.tsx

默认语言、持久化与 `<html lang>` 同步。

**1. 默认语言改为繁体，支持 5 种语言**

```ts
const StringsContext = createContext<UIStrings>(localeStrings.zh);
const LocaleContext = createContext<Locale>("zh");
```

改为：

```ts
const DEFAULT_LOCALE: Locale = "zh-TW";
const SUPPORTED_LOCALES: Locale[] = ["zh-TW", "zh", "en", "ja", "ko"];

const StringsContext = createContext<UIStrings>(localeStrings[DEFAULT_LOCALE]);
const LocaleContext = createContext<Locale>(DEFAULT_LOCALE);
```

**2. 新增 `HTML_LANG` 映射，切换 / 初始化时同步 `document.documentElement.lang`**

```ts
const HTML_LANG: Record<Locale, string> = {
  "zh-TW": "zh-Hant",
  zh: "zh-Hans",
  en: "en",
  ja: "ja",
  ko: "ko",
};
```

**3. localStorage 持久化**

存储键为 `omnistack-locale`，读取时按 `SUPPORTED_LOCALES`（5 种）校验，非法值回退到 `DEFAULT_LOCALE`。
